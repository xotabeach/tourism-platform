## Visual language (как в актуальном макете)

- Формат экранов: **393×852** (часть экранов выше — длинный scroll: Главная ~2721, Карточка ~2393, Профиль ~1005).
- Светлый UI + **photo-first** hero (пейзажи Крыма).
- Акцент в коде уже есть (`AppColors`); в макете профиля видны синие круги под иконки достижений — сверяй с `tourism-mobile/lib/core/design/`.
- Floating **liquid glass** bottom chrome / pill CTA «Начать путешествие».
- Крупные радиусы карточек (~24–30), мягкие тени.
- Tab / actions: thin outline icons (в файле есть фрейм `Icons` `41:1165`).
- Бренд в шапках настроек: **КРЫМТРИП**.
- Подписка: **ТРЕВЕЛ +** / очки **тп** (ТревелПоинт).

### Структура сверху вниз

1. **Hero header** (фото побережья на закате)

   - Имя: **Никита Можаров** (белый bold)
   - Подзаголовок звания: **Продвинутый пешеход**
   - Справа круглая кнопка ⋯ (more) → вход в настройки
2. **Карточка звания** (белая, overlap на hero ~−28px как в Flutter)
   - Ряд: `Звание:` · **Продвинутый пешеход**
   - Progress: pill `1452 / 1800 тп` + bar + pill `Топ 1345`
3. **Достижения:** (заголовок)
   - Горизонтальный pager карточек:
     - Марафонец — «Пройти суммарно 48 км за неделю»
     - Ты норм? — «Вернуться по тому же маршруту»
     - Ура Советам — «Дойти пешком до Берлина»
   - У каждой: синий круг-иконка слева, chevron справа
   - Dots pagination
4. **Популярные маршруты** (в макете; в Flutter сейчас «Опубликованные маршруты» / избранное — сверить продукт)
   - Карточка маршрута с фото: **Гора Чок-Сары-кая**, Бахчисарай, 8,6 км
   - На карточке мини-профиль автора + edit
5. Floating glass actions / CTA «Начать путешествие» (общий паттерн файла)

### Статус в коде

`tourism-mobile/lib/features/profile/presentation/profile_screen.dart`:

## Инструкция агенту Cursor (без Figma)

1. Читай этот файл + `figma-screens-extract.json` + `profile-screen.png`.
2. Реализуй во `tourism-mobile` feature-first (`presentation` / `application` / `domain`).
3. Не выдумывай экраны вне списка; если чего-то нет в коде — создай routes/screens по IA выше.
4. Приоритет для незавершённого профиля:
   1. Навигация Профиль ⋯ → Настройки
   2. Корень настроек (active/inactive subscription banner)
   3. Уведомления / Оффлайн / Профиль-edit
   4. Поддержка FAQ + чат (можно mock)
   5. Репорт ошибки + thank-you
   6. Тревел + paywall
5. Копирайт бери из JSON; очевидные опечатки макета в UI-строках можно поправить (удоства→удобства, Асистент→Ассистент, Слонжость→Сложность) — отметь в PR.
6. Стиль: существующие `AppColors` / `AppRadii` / `NativeLiquidGlass` / typography — не тащи чужой Gemini neural mesh.
7. После UI: `./scripts/validate.sh` или `make mobile-check`.
