## 3. Пунктир — как устроен в Figma (асимметрия)

По zoom-референсу (`banner zoom.png`) и дереву слоёв:

Пунктир — это **не** тонкая линия `stroke` по одной окружности.
Это **полоса-трек** толщиной ~10 pt между Ellipse 8 и Ellipse 10,
внутри которой лежат тёмно-синие «таблетки»-штрихи.

```text
                    внешняя кромка (R=111) — более резкая / плоская
                 ╭─────────────────────────────────╮
                 │  ▓▓▓▓    ▓▓▓▓    ▓▓▓▓    ▓▓▓▓   │  ← dash pills
                 │                                 │
                 ╰─────────────────────────────────╯
                    внутренняя кромка (R=101) — мягче / скруглённее
                         ↑ светлый диск Ellipse 8
```

### Параметры штрихов (pixel-measure + zoom)

| Параметр | Значение | Источник |
|---|---|---|
| Цвет dash | `#1537E7` | pixel-measure / code |
| Длина dash вдоль дуги | **9 pt** | pixel-measure |
| Gap | **2.6 pt** | pixel-measure |
| Толщина dash (радиальная) | ≈ **2.8–3 pt** тонкий stroke (не заливка кольца 10 pt) | screenshot `travel+ banner.png` 2026-07-31 |
| Внешняя сторона dash | плоская, острая, ближе к R=111 | zoom |
| Внутренняя сторона dash | мягко скруглённая, ближе к R=101 | zoom |
| Прозрачность dash | 100% (без альфы) | pixel-measure |
| Видимый сектор | от ~9 часов до ~12 часов (левая-верхняя четверть окружности) | meta + zoom |

### Как рисовать во Flutter

```text
1. Светлый диск: circle(center, R=101), fill white @ ~7%
2. Для каждого dash-сегмента вдоль дуги R_mid≈106 (или по outer):
   - построить annular sector между R_inner=101 и R_outer=111
   - outer corners: sharp / butt
   - inner corners: rounded (fillet ≈ 0.5…0.55 × radial thickness)
3. НЕ рисовать два сплошных ring-stroke поверх диска
4. Маркер-стрелка — Vector 280:4800, сидит на треке
```
