## 1. Баги — правятся сразу

- [x] **Счётчик лайков расходился** между карточкой и экраном статьи. Оптимистичный
  оверлей жил только на экране чтения, карточка показывала число из своего списка.
  Теперь карточка смотрит в тот же оверлей.
- [x] **Клавиатуру нельзя закрыть** при написании комментария к статье. Добавлены
  тап мимо поля и закрытие протяжкой — как в редакторе.
- [x] **У достижений в профиле не было иконок** — рисовался пустой цветной кружок.
  Карта иконок вынесена из карточки достижения в общий модуль.
- [x] **В админке нельзя одобрить комментарий блога.** `set_comment_status` был
  написан, но его никто не вызывал: у комментария на модерации не было пути
  к публикации. Добавлены действия «Одобрить» / «Отклонить».
- [ ] **Дата в карточке блога** — по коду и голденам она справа; нужен скрин
  случая, где она слева, иначе непонятно, что чинить.
- [x] **Профиль грузится без скелетона**, аватар и фон подставляются моковые
  вместо реальных. Скелетон был на месте; фото брались из локальной сессии,
  которая знает только загруженное на этом устройстве.
- [x] **Кривое поле ввода бюджета** — `isCollapsed` отключает вертикальное
  центрирование. Попутно починен невидимый отклик на нажатие у тумблеров.
- [ ] **Прелоадер** — перепроверить качество картинки на устройстве.

## 3. Крупные фичи — отдельными заходами

- [x] **Рейтинги маршрутов.** Фиктивная формула из длины названия убрана.
  Бэкенд считает среднее одним `GROUP BY` на страницу (опубликованные отзывы,
  без ответов); маршрут без оценок звезду не показывает вовсе. В деталях —
  «4,3 (12)» с переходом к отзывам. Проверено на проде: единственный маршрут
  с отзывами показывает 5,0 (3), остальные — без звезды.
  Не сделано намеренно (было в спеке как «решить»): байесовское сглаживание —
  нужно только если появится сортировка по рейтингу, её сейчас нет; и оценка
  без текста — меняет модель отзыва.
- [x] **Редактор фото перед загрузкой**: кадрирование, масштаб, поворот.
  Собран на `dart:ui` — без нативных плагинов, рамка по нашему дизайну (круг
  для аватара, 16:9 для обложек и фото). Геометрия вынесена в чистые функции
  и покрыта тестами: превью и итоговый рендер считают одно и то же, иначе
  загруженное не совпало бы с кадром. Подключён к аватару, обложке, фото
  статьи и фото маршрута. Фото отзывов — намеренно нет: там множественный
  выбор, и кадрировать каждое подряд было бы назойливо.
- [x] **Travel+: гифки в фон профиля.** GIF сохраняется байт-в-байт (обычный
  путь пересжал бы его в один кадр). Лимиты свои: 8 МБ, 300 кадров, 2 МП на
  кадр. Только обложка — анимированный аватар шевелился бы в каждом списке.
  Подписка проверяется на сервере, не по слову клиента.
- [ ] **Travel+: смена стиля иконки приложения.** Варианты предзагружаем, смена —
  только с подпиской. На Android — `activity-alias`, на iOS —
  `setAlternateIconName`; обе платформы требуют, чтобы наборы иконок были
  вшиты в сборку заранее.
- [ ] **DeepSeek как провайдер ИИ.** Рассмотреть рядом с Gemini: у нас уже есть
  слой провайдеров (`AI_PROVIDER`), так что это в основном вопрос цены,
  качества на русском и доступности из Москвы без релея.
